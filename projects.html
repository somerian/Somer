Guyana Land Use/Land Cover Classification

Remote Sensing Course Project · San Francisco State University

Multi-temporal land cover change analysis of Jawalla village in Guyana using Landsat 5 (1986) and Sentinel-2 (2016) imagery. Applied atmospheric correction, cloud masking, and supervised classification to identify changes in forest, savanna, and other land cover types.

Remote Sensing ERDAS Imagine SNAP Supervised Classification

Spatial analysis examining the relationship between community orchards and food security (SNAP usage) in San Francisco, Alameda, and Sonoma counties. Used geocoding, buffer analysis, and census data integration.
